## 💡 Key features

API Sentinel includes tools for common technical tasks. Use these features to streamline your daily work.

### API testing
Send requests to your endpoints and view the data responses. The application supports various methods including GET, POST, PUT, and DELETE. You can inspect headers, bodies, and status codes for every request.

### Mock servers
Create your own mock server when you lack a live backend. Define your responses and simulate real API behavior. This helps your team build features before the final service exists.

### Load testing
Check how your software handles high traffic. Set up a load test to send multiple requests to your server. Monitor response times and failure rates to improve system stability.

### Automation
Save your common steps into collections. Use the automation tools to run these sequences in a specific order. This feature reduces manual work and ensures consistent test results.

### Protocol support
Work with modern technology stacks. API Sentinel handles REST, GraphQL, and WebSockets. It also supports MQTT and Socket.io for real-time data communication.

## 📝 Troubleshooting common issues

Most users find the installation process straightforward. If you encounter difficulties, check these common areas.

### The app does not launch
Verify that you downloaded the Windows version. Check if your antivirus software blocked the installer. Sometimes Windows SmartScreen stops unrecognized files. If this happens, select More Info and choose Run Anyway.

### Requests fail
Check your local internet connection first. Ensure that your firewall allows outgoing traffic for the application. If you target a local server, check that your server runs on the correct port and host address.

### The interface feels slow
Large collections with thousands of requests can consume significant memory. Close other unused applications to free up system resources. Update your software to the latest version to get performance patches.
